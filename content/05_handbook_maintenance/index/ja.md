# ハンドブックの保守

ハンドブックを編集し、権限を持つ研究室管理者へ移管するための準備方法を学びます。

## ページの編集

エディタを開き、Git の最新リビジョンを読み込み、一つの言語で編集して Markdown を確認し、コミットします。原文の意味を変えない表現修正に限り翻訳修正モードを使います。非公開情報を含めずに Issue で翻訳の問題を報告できます。

## 公開前のレビュー

公開と翻訳サービス利用の許可を確認してください。技術手順、数値、単位、エラー、警告、各言語版を確認します。草稿は検証済みの操作手順ではありません。

## 管理の移管

リポジトリには Markdown とビルドスクリプトがあります。管理者はローカルで静的サイトを生成し、許可されたウェブサーバーで配信できます。編集機能と CI は内部 Git サービスに合わせる必要があります。内部資料を追加する前に認証情報を更新し、アクセス制限を検証してください。
