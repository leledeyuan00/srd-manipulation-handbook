# 手册维护

学习如何参与编辑，并为将网站移交给实验室授权管理员做好准备。

## 编辑页面

打开编辑器，加载 Git 最新版本，使用一种语言编辑，检查 Markdown 后提交。仅在修正措辞且不改变原义时选择翻译修正模式。可通过 Issue 反馈翻译问题，但不得附带受限信息。

## 发布前审核

确认公开发布与翻译服务使用权限。检查技术步骤、数值、单位、错误信息、警告及各语言版本。草稿不是验证过的操作流程。

## 移交维护权

仓库包含 Markdown 和构建脚本。维护者可本地生成静态网站并使用授权服务器托管。在线编辑器及 CI 配置需要适配内部 Git 服务。添加内部资料之前，应轮换凭据并验证访问控制。
