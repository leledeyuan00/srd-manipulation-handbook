# Lessons learned

Learn how to document an engineering issue so that future students can diagnose it without repeating the same mistakes.

## Troubleshooting record

Record the symptom, exact error message (if cleared for publication), test conditions, evidence, verified cause, verified fix and validation result. Mark hypotheses separately. Link to the relevant chapter instead of duplicating instructions.

> **WARNING:** Never bypass protective circuits or improvise calibration and recovery steps. Use official procedures and authorized supervision.
