# SRD Manipulation Handbook

A living knowledge base for the Smart Robots Design Lab at Tohoku University. Learn how the lab's manipulation platform works, how to collect demonstrations, train a policy, and deploy it safely.

> **Draft — review required.** This starter contains outlines, not verified operating instructions. Never use it as a substitute for official safety procedures.

> **Publication policy:** while hosted on personal GitHub Pages, this entire repository and site must contain only material approved for public disclosure and authorized for any external translation service. Do not enter restricted information, including in drafts, commits, issues or images.

## How to contribute

Use **Edit page** to open the editor. Write in English, Japanese, or Chinese. Select translation correction mode only when fixing wording in one language. Review commands and warnings before publishing.
