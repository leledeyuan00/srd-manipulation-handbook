Online editor

Write in your preferred language. The repository is the source of truth; load the latest revision before editing.

Use a fine-grained personal access token restricted to this repository, with Contents: Read and write. The token is kept only in this page's memory and sent to api.github.com; it is not stored or embedded in the site. Only enter credentials on the trusted lab site. Public-safe material only: never enter confidential, internal-only or unapproved content. Review all safety-critical changes before publication.

New pages use chapter/topic-slug, e.g. 03_denso_system/calibration. Use assets/... for shared image links; upload assets to GitHub separately in this version.

Load a page or create a new page to begin.

Saving creates a commit; published pages update after GitHub Actions passes. Conflicting edits are rejected. This prototype writes to the default branch and requires repository write permission.
